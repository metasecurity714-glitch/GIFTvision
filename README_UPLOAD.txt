CLASSVISION WEBSITE FILES

Upload these three files to the ROOT of your existing GitHub repository, replacing files with the same names:
- index.html
- app.js
- style.css

Do not upload this README as a website file; it is only an instruction note.

After upload, commit the changes and wait for GitHub Pages to publish. Open the HTTPS site in Chrome on Android.

ESP32 firmware is a separate file: ClassVision_ESP32_BLE.ino. Open that file in Arduino IDE and upload it to the ESP32 Dev Module.

Note: this implementation uses registered student roll-number lookup plus operator confirmation; it does not identify students by face. Records are stored in this browser's local storage and do not automatically sync across devices.
